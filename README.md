### Option 2: Download and Run Locally
1. Go to the repository: https://github.com/RiteeshV/COMP5427-Figma-Design
2. 2. Click the green **Code** button
   3. 3. Select **Download ZIP**
      4. 4. Unzip the folder on your computer

                                 16. If you forked this repo and want your own live link:
                                
                                 17. 1. Go to your forked repo on GitHub

                                           4. 4. Under **Source**, select **Deploy from a branch**
                                              5. 5. Choose **main** branch and **/ (root)** folder
                                                 6. 6. Click **Save**
                                                    7. 7. Wait 1–2 minutes — your live link will appear at:
